စာပေကမ္ဘာ Website - စတင်အသုံးပြုနည်း

ပါဝင်သောဖိုင်များ
- index.html : Website စာမျက်နှာ
- style.css : ဒီဇိုင်း
- data.js : စာအုပ်/အသံဖိုင် စာရင်း
- app.js : ရှာဖွေခြင်း၊ ဖွင့်ခြင်း စနစ်

ဖုန်းဖြင့် GitHub Pages တင်ရန်
1. ZIP ကို ဖြည်ပါ။
2. Chrome ဖြင့် https://github.com ကိုဖွင့်ပြီး သင့်အကောင့်ဝင်ပါ။
3. Repository ကိုဖွင့်ပါ။
4. Add file > Upload files ကိုနှိပ်ပြီး ဖိုင်များတင်ပါ။
5. Commit changes လုပ်ပါ။
6. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save ကိုရွေးပါ။
7. မိနစ်အနည်းငယ်စောင့်ပြီး https://sape-kabarwa.github.io/ ကိုဖွင့်ပါ။

စာအုပ်/အသံဖိုင် ထည့်ရန်
1. Google Drive ထဲသို့ PDF သို့မဟုတ် MP3 ဖိုင်တင်ပါ။
2. Share > General access > Anyone with the link > Viewer ကိုရွေးပါ။
3. Copy link ကိုနှိပ်ပါ။
4. data.js ကိုဖွင့်ပြီး BOOKS သို့မဟုတ် AUDIOS စာရင်းထဲတွင် သင့်အချက်အလက်နှင့် link များကို အစားထိုးပါ။
5. data.js ကို GitHub repository ထဲသို့ ပြန်တင်ပြီး Commit changes လုပ်ပါ။

အရေးကြီး
- ဒီ Version သည် Front-end နမူနာဖြစ်ပြီး Website ထဲတွင် လုံခြုံသော Admin Login/Upload စနစ် မပါသေးပါ။
- GitHub repository ကို ကိုယ်တိုင်ထိန်းချုပ်ထားပါ။ အခြားသူများကို Write access မပေးပါနှင့်။
- Google Drive share link သည် လူတိုင်းကြည့်နိုင်အောင်ဖွင့်ထားလျှင် အဲဒီဖိုင်ကို link ရသူတိုင်း ဝင်ကြည့်နိုင်သည်။
- Google Drive link အချို့သည် Website player ထဲတွင် တိုက်ရိုက်မဖွင့်နိုင်ပါ။ တိုက်ရိုက် MP3 URL သို့မဟုတ် သင့် browser မှ ခွင့်ပြုသော audio hosting လိုနိုင်သည်။
- မူပိုင်ခွင့်ရှိသော စာအုပ်/အသံဖိုင်များကို ခွင့်ပြုချက်မရှိဘဲ မတင်ပါနှင့်။
